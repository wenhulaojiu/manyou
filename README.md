# 慢游 · 本地路线规划

需要 Node.js 22.12 或以上。运行 `npm ci --ignore-scripts`、`npm start`，打开 http://127.0.0.1:4173/。服务只监听本机，不收费。

支持铁路目录城市与指定车站，可选两个优先中转城市。关闭自动枢纽并取消优先城市时仅查直达。自动搜索先参考时刻索引和 12306 中转建议安排候选，再逐段核实价格、余票及换乘时间；仍未穷举全国所有路线。缺少或过期的时刻数据只会失去排序优化，不会据此删除候选。

选择停留晚数后只推荐满足停留的中转路线。最快直达基准遵守预算、最长赶路与跨夜条件；没有基准时无法判断时间价值，启用“只看符合时间价值”将排除这些路线。铁路卧铺偏好只约束铁路，不会误删航班。指定火车站会排除该端航空方案。

路线计算通过 Comlink 在 Web Worker 中执行。后台保留完整候选，页面只获取推荐、已展开候选和选中对比项；展开更多和切换排序复用计算缓存。中转按出发时间窗口筛选，再精确计算换乘。改变行程条件会清除旧结果。

铁路使用 12306-mcp 0.3.10，保留有票且有明确价格的非无座席别，预售窗口为 15 天。每次搜索拥有独立 MCP 连接；每组站点/机场查询通过 p-queue 排队，最多 3 个并发、每 500 毫秒启动 2 项，铁路连接自身串行。局部失败保留成功数据。取消带查询编号，旧搜索的回调和连接清理不会影响新搜索。

总预算 180 秒；铁路和航空区间预算直达 30 秒、中转 15 秒。中转建议最多等待 8 秒。取消、区间超时和总超时终止等待，保留增量结果。覆盖说明区分失败、未配置、部分完成和按条件排除。

机票需将 `.env.example` 复制为 `.env` 后配置 AMADEUS_CLIENT_ID、AMADEUS_CLIENT_SECRET。默认 test，仅 AMADEUS_ENV=production 使用生产环境。当前没有账号配置，测试使用 MSW 模拟服务，不代表真实机票覆盖。机场目录来自 airportsdata，包含 256 个带 IATA 代码的中国机场，其中 170 个已映射到项目城市。上海 SHA/PVG、北京 PEK/PKX、成都 CTU/TFU 均逐机场组合查询；目录中有机场不代表供应商提供报价或机场仍有定期客运。未确定城市归属的机场保留在数据中，不强行匹配。只查人民币、单段直飞，每对机场最多 250 个报价，达到上限会提示部分覆盖。

## 数据更新

已打包 `data/airports.json` 和 `data/rail-index.json`，运行应用不需要下载 GTFS。`npm run data:update` 从缓存或固定版本源生成数据；`node scripts/import-data.mjs airports --refresh` 重新下载机场目录。下载直接连接失败时尝试 Python 3 urllib 的系统代理；没有 Python 时可配置网络或手工将文件放入 `data/cache/`。

当前铁路快照 `gtfs-20261024-052143`，源 ZIP SHA-256 为 `b498ed6e7c0c2f1c8828f8939762bdeff67793df63ab6a62debab0c926570076`。导入只读取 GTFS 站点、车次、停站时间、运行日期和 feed 元数据，不导入价格或余票。GTFS 超过 24:00 的停站时间按始发运行日正确换算；时刻排序只在服务日期范围内且快照未超过 3 天时启用。重新导入同一个旧 ZIP 不会延长其有效期。

更新铁路版本须从 [上游 Releases](https://github.com/wensimehrp/chinese-railway-gtfs/releases) 确定 release 与对应资产校验值，再运行：

```
node scripts/import-data.mjs rail --release=gtfs-YYYYMMDD-HHMMSS --sha256=资产的完整SHA256值
```

`data/cache/` 不纳入版本控制。生成文件保存来源、版本、导入时间、源数据校验值；修改数据后重启服务。上游站点坐标来自 OpenStreetMap，使用 WGS84，不应直接作为国内地图导航坐标。

## 验证与授权

`npm test` 运行规划规则、时刻索引、MSW 航空接口/流式传输、MCP 生命周期与本地 HTTP 集成测试，不访问真实票务服务。浏览器还需验证演示查询、筛选、排序、分页、对比及实时取消。真实铁路查询受上游服务和网络可用性影响；没有 Amadeus 生产账号时无法验收生产机票数据。

来源与许可证在页面 `/sources.html`、`THIRD-PARTY-NOTICES.md` 和 `licenses/`。铁路索引为 CC-BY-4.0 数据的转换结果；OSM 坐标保留 OSM 署名。库版本在 package-lock.json 锁定。针对 GHSA-mrhx-c7xc-m3w5，将 12306-mcp 的 Zod 依赖覆盖为 4.6.7；已验证真实 MCP 工具注册、车站查询、余票查询及中转建议接口。GitHub 选型依据见 GITHUB-REUSE-RESEARCH.md。

现金预算包含票价、接驳、中转交通、住宿；综合成本再加赶路小时乘时间价值。主动游玩单列，餐饮、景点及额外行李不计。分段购票无联程保障，购票前核实余票、票价和换乘。账号、支付、公网部署和商用票务授权尚未实现。

`dist/` 为当前前端源文件，后端需要 Node 和子进程环境，不能仅上传静态文件。旧原型脚本与静态托管配置保持停用。
